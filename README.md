An advanced Human-Computer Interaction system that enables touchless computer control using hand gestures.

✨ Features:
- Real-time hand tracking using MediaPipe
- Detection of 21 hand landmarks
- Contactless cursor control
- Gesture-based scrolling
- Transparent virtual whiteboard
- Multi-threaded processing pipeline

**Tech Stack:** Python, OpenCV, MediaPipe, Machine Learning
